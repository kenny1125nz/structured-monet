# Structured / Monet

This repository is the `Monet` folder from the structured workspace. It currently contains a **Graph Designer Tool** implementation (React + TypeScript + Vite) for graph-shaped system models.

## Features

- Graph-as-data modelling of components and relationships
- Visual graph view plus JSON editing with CodeMirror
- Import/export of model data

## Getting started

```bash
npm install
npm run dev
```

```bash
npm run build
npm run typecheck
```

## Note

The folder is named `Monet`, but the package is `graph-designer-tool`; treat this as the structured-workspace variant of the graph designer rather than the Monet agent orchestrator.
